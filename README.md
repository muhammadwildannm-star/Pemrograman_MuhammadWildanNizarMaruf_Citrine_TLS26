# Pemrograman_MuhammadWildanNizarMaruf_Citrine_TLS26
Muhammad Wildan Nizar Ma'ruf dari Kelompok Citrine.
Repository ini berisi penyelesaian dari problem 1 dan 2 dari penugasan Teti Lab Skill 2026 yang menggunakan bahasa C++. Problem 1 berkaitan dengan logika eleminasi astronot dengan penentuan jumlah astronot, penentuan astronot yang pertama dieliminasi, urutan astonot yang dieliminasi, dan astronot terakhir yang bertahan. Problem 2 adalah bahasa alien atau transkripsi teks menjadi enskripsi.
